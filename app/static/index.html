ℹ️ System Architecture & Hydrological Algorithm

1. End-to-End Pipeline

Step 1: Input Terrain

Accepts user click point, drawn bounding box, or uploaded KML/KMZ contour lines. Unzips and parses scattered coordinate elevations.

Step 2: Elevation Grid

Converts scattered 3D contours into a continuous GeoTIFF DEM via SciPy 2D linear Delaunay interpolation with nearest-neighbor convex-hull filling.

Step 3: D8 Hydrological Analysis

Priority-flood fills depressions, resolves flats, calculates D8 steepest-descent flow directions, and computes upstream flow accumulation.

Step 4: Optimal Site & Runoff

Discovers the maximum convergence interior cell as the suggested pond site. Delineates the basin polygon and calculates expected runoff via the Rational Method: $Q = C \cdot I \cdot A$.

2. Rational Method Formulation

$Q = C \times I \times A$

  • $C = 0.35$: Runoff coefficient for rural/agricultural land cover in central India.
  • $I$: Design seasonal monsoon rainfall intensity (meters), queried from Open-Meteo historical reanalysis.
  • $A$: Delineated upstream catchment surface area ($m^2$) computed from D8 flow routing.
  • Capacity: $V_{target} = 0.70 \times Q$ (sizes pond for 70% seasonal capture).

3. System Specifications

Built as a high-performance modular monolith with FastAPI, Rasterio, PySheds, GeoAlchemy2, PostgreSQL/PostGIS, and Leaflet.js.
